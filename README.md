# Villa Lijó Suítes — Guia Digital para TV

Primeira versão demonstrativa de uma página web para abrir no navegador da televisão.

## Ficheiros
- `index.html` — aplicação completa (HTML, CSS e JavaScript no mesmo ficheiro).

## Como testar no computador
1. Extraia o ZIP.
2. Faça duplo clique em `index.html` para abrir no navegador.
3. Pode testar a identificação de suíte acrescentando à morada `?suite=PONTE`, por exemplo.

## Como publicar no GitHub
1. Abra o repositório `villa-lijo-tv`.
2. Escolha **Add file → Upload files**.
3. Carregue `index.html` e `README.md`.
4. Prima **Commit changes**.

## Como publicar gratuitamente com GitHub Pages
1. No repositório, abra **Settings → Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/(root)`, depois **Save**.
4. Aguarde a publicação. O endereço será semelhante a `https://paulojfsf-creator.github.io/villa-lijo-tv/`.

## Personalização pendente antes de usar com hóspedes
- Inserir nome e palavra-passe reais da rede Wi-Fi (não os publique num repositório público).
- Confirmar os textos e regras da casa.
- Testar o navegador VIDAA e a navegação com o comando da Toshiba 32WV3563DG.
- A página é uma demonstração estática; ainda não inclui painel de administração, reservas, PMS ou tradução de interface.
