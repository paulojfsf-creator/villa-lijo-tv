# Villa Lijó Suítes — Guia Digital TV

Versão visual premium com fotografia de destaque da propriedade/paisagem.

## Publicar no GitHub Pages
1. Descarregue e extraia o ZIP.
2. Copie `index.html` e `villa-lijo-geres.png` para a raiz do repositório `villa-lijo-tv`.
3. Confirme que ambos os ficheiros ficam ao mesmo nível.
4. Faça Commit changes e aguarde alguns instantes.
5. Abra https://paulojfsf-creator.github.io/villa-lijo-tv/

A imagem é carregada localmente a partir do ficheiro `villa-lijo-geres.png`, por isso tem de ser publicada junto do `index.html`.
